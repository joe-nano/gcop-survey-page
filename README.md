# gCOP audit survey landing page

Static page for the gCOP audit survey and GPOC re-audit (Imperial College London, Institute of Global Health Innovation).
It generates each respondent's anonymous code in their browser, links to the Microsoft Forms, and shows the information
sheets. It sets no cookies, loads nothing from other sites and sends no data anywhere.

An audit, as confirmed by Imperial College London; published 17 November 2026.
Address: https://joe-nano.github.io/gcop-survey-page/
